# 虎鲸链路（ORCA LINK）

虎鲸链路是为 DSH Web GUI 定制的轻量二次元科幻皮肤，从
[`orca-link` bundle](https://github.com/Small-tailqwq/dsh-deep-whale/tree/main/orca-link)
移植为 manifest-v2 资产皮肤接入皮肤中心。珍珠白机械舱、黑曜虎鲸操作员与克制的
电蓝链路信号贯穿侧栏、会话与输入区；亮色以眨眼角色迎接新会话，暗色切换为深海
操作台氛围。

本版保留原配色、背景叙事与机械硬朗轮廓，不含原插件的交互脚本。
