# ORCA LINK

ORCA LINK is a light sci-fi anime skin for the DSH Web GUI, ported from the
[`orca-link` bundle](https://github.com/Small-tailqwq/dsh-deep-whale/tree/main/orca-link)
as a manifest-v2 asset skin for the Skin Center. Pearl-white mechanical cabin,
obsidian orca operator, restrained electric-blue link signals across the
sidebar, conversations and the composer; the light theme greets with a
blinking character and the dark theme turns into an abyssal operations deck.

This port keeps the original palette, background narrative and rectilinear
mechanical shape; it does not include the original bundle's interactive
scripts.
