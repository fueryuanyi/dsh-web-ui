# 滑动变阻器（Liang Intensity）

滑动变阻器是一套以金铜品牌色与暖黑材质为基调的安静工作皮肤，从
[`dsh-liang-skin`](https://github.com/kingOfSoySauce/dsh-liang-skin) bundle
移植为 manifest-v2 资产皮肤接入皮肤中心。暗色采用梁式原版配色并以静默立绘作
背景，亮色为同一金铜色系的暖象牙纸感。

本版保留配色气质，并经皮肤中心交互 hooks 面实现真推理强度滑块：拖拽真实修改当前模型推理强度，联动 6 段调色板插值与立绘档位切换。
