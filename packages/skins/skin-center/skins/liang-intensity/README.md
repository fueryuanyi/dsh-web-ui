# Liang Intensity

Liang Intensity is a quiet working skin with a bronze-gold brand color and
warm-black materials, ported from the
[`dsh-liang-skin`](https://github.com/kingOfSoySauce/dsh-liang-skin) bundle as
a manifest-v2 asset skin for the Skin Center. The dark theme pairs the real
Liang palette with a silent portrait backdrop; the light theme is a warm
ivory-paper take on the same bronze family.

This port keeps the color temperament only; it does not include the original
bundle's reasoning-effort slider interaction.
